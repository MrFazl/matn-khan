# متن‌خوان — Matn-Khan

نمایش‌گر راست‌به‌چپ Markdown در یک فایل HTML واحد؛ متن کپی‌شده از هوش مصنوعی را جای‌گذاری کنید و خوانا بخوانید — با پشتیبانی از جدول، کد (با دکمه‌ی کپی)، فهرست خودکار، فهرست کارها، تم روشن/تاریک و نصب به‌صورت برنامه (PWA).

**نسخه‌ی زنده (GitHub Pages):** https://mrfazl.github.io/matn-khan/

## استفاده

کافی است `index.html` را باز کنید یا به نسخه‌ی زنده بروید، متن Markdown را با `Ctrl+V` جای‌گذاری کنید. همه‌چیز سمت کاربر اجرا می‌شود و هیچ داده‌ای به سرور ارسال نمی‌شود.

A single-file RTL Markdown viewer for reading AI-generated text in Persian/Arabic scripts. Paste Markdown and read it beautifully rendered — tables, code blocks with copy buttons, auto table of contents, task lists, light/dark themes, installable as a PWA. Everything runs client-side; no data leaves your browser.
